# HekSoftware Masaustu

Yazilimsal hizmetler ve bilgisayar malzemeleri icin hazirlanmis WinForms tabanli masaustu siparis uygulamasi.

Demo hesaplar:

- Admin: `admin` / `1234`
- Musteri: `denememusteri` / `123456`

Ozellikler:

- Musteri kaydi ve admin onay akisi
- Admin uye bilgileri takibi
- Musteri hizmet ve malzeme paneli
- Hizmet/malzeme detayi penceresi
- Sepete ekleme, adet degistirme ve siparis olusturma
- Siparis gecmisi ve siparis detaylari
- Admin katalog yonetimi
- Admin urun ve stok takibi
- Admin siparis merkezi
- Admin raporlama ekrani
